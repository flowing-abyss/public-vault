Rules – это правила в `manifest.md`, которые автоматически изменяют метаданные. У каждого есть `when` (когда срабатывает) и `then` (что делает). Если правило нужно сразу нескольким манифестам, то оно лежит в `rules.md` и действует на все манифесты в той же папке и глубже. Срабатывают при открытии и сохранении заметки, а также через команду Autofix.

Разберём три правила.

Для начала самое простое, которое ставит дату начала. Перевели задачу в 🟦 (wip), и `start` установился сам:
```yaml
- name: start on wip
  when: "status=🟦 AND start="
  then:
    set: { start: "{{today}}" }
```

Читается так: когда статус 🟦 и `start` пустой, тогда записать в `start` сегодняшний день.

Теперь правило посложнее, которое смотрит в другую заметку. Задача (tasknote) наследует категорию у своего проекта:
```yaml
- name: category follows project
  when: { project: { when: "-category=" } }
  then:
    set: { category: "{{project>category}}" }
```

Читается так: если у задачи указан проект и категория у этого проекта не пустая (`-category=`), то забрать её себе.

И последний пример, уже из двух правил. Если задача ждёт другую, то она уходит в ❄ (заморожена), а когда та закрыта, возвращается в 🟥 (запланирована):
```yaml
- name: hold while blocked
  when:
    and:
      - "status=📥 OR status=🟥"
      - blockedBy: { when: "status=📥 OR status=🟥 OR status=🟦 OR status=❄" }
  then:
    set: { status: ❄ }

- name: release when unblocked
  when:
    and:
      - "status=❄"
      - blockedBy: {}
      - not:
          - blockedBy: { when: "status=📥 OR status=🟥 OR status=🟦 OR status=❄" }
  then:
    set: { status: 🟥 }
```

Первое правило: задача лежит в 📥 (инбокс) или 🟥, и среди её блокеров есть незакрытая. Значит, замораживаем. Второе делает обратное: задача заморожена, блокеры у неё есть (`blockedBy: {}`), и незакрытых среди них не осталось (`not`). Значит, возвращаем в 🟥.

Возможно, это покажется сложным :) Но правила просто повторяют типичные действия из рабочего процесса. Раньше всё это нужно было отслеживать и прокликивать руками, теперь оно делается само.
